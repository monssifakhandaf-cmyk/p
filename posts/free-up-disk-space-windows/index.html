How to Free Up Disk Space on Windows: 8 Safe Ways

November 7, 2026 · 2 min read

A full drive slows Windows down, blocks updates and stops you from saving files. The good news: you can usually recover several gigabytes using only tools that are already built in. Here are eight safe methods, from the quickest wins to the deeper clean-ups.

1. Run Storage Sense

Open Settings > System > Storage and turn on Storage Sense. It automatically removes temporary files and empties the Recycle Bin on a schedule you choose. Click Run Storage Sense now to clean immediately.

2. Use Disk Cleanup for system files

Search for Disk Cleanup, select your main drive, then choose Clean up system files. Tick items such as Windows Update Cleanup, Temporary files and Thumbnails. Review the list before confirming, and leave Downloads unticked unless you are sure you do not need those files.

3. Uninstall programs you no longer use

Go to Settings > Apps > Installed apps, sort by size and remove anything you have not opened in months. Large games and old design or video tools are the usual culprits.

4. Find the biggest folders

Open Settings > System > Storage and click each category to see what is using the most space. Knowing where the space went makes every other step faster. The free tool WizTree gives an even clearer map of your largest files.

5. Move big files to another drive or the cloud

Videos, backups and disk images take the most room. Move them to an external drive, or to a cloud service with free storage, and keep only what you use often.

6. Clear the Windows Update leftovers

After a major update, Windows keeps files that let you roll back. In Disk Cleanup, tick Previous Windows installation(s) if it appears. Only do this once you are happy the new version is stable, because you will not be able to roll back afterwards.

7. Reduce hibernation and restore point size

If you never use hibernate, you can turn it off from an administrator Command Prompt with powercfg /h off, which frees space roughly equal to a fraction of your RAM. You can also lower the amount of space System Restore uses under System Properties > System Protection.

8. Empty browser caches

Browsers store images and site data that can reach a few gigabytes. Clear the cache from your browser's privacy settings. Pages may load a little slower the first time afterwards, then the cache rebuilds on its own.

Quick checklist

  • Run Storage Sense
  • Clean up system files
  • Remove unused apps
  • Move large files off the main drive
  • Clear browser cache

Do these in order and stop as soon as you have enough free space. Aim to keep at least 15 percent of your drive free so Windows has room to work.

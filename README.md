# Ant Smash Shorts Factory — مصنع فيديوهات الشورتس

ينتج فيديوهات شورتس **عمودية 1080×1920 (20 ثانية) بصوت وموسيقى وعنوان ووصف ووسوم**، جاهزة للرفع، دون تسجيل الشاشة يدويًا.
البوت يلعب اللعبة، والمصنع يسجّل ويركّب الصوت ويكتب النصوص.

## التثبيت (مرة واحدة)
1. ثبّت **Node.js 18+** و **ffmpeg** (يجب أن يعمل الأمر `ffmpeg -version`).
2. داخل هذا المجلد:
```
npm install
npx playwright install chromium
```

## الاستخدام
```
node factory.js make --count 3          # 3 فيديوهات متنوعة
node factory.js make --concept bee_fail # فيديو من فكرة محددة
node factory.js plan --count 5          # معاينة ما سيُنتج دون تسجيل
node factory.js report                  # تقرير التنوع
```
النتائج في مجلد `out/`: لكل فيديو ملف `.mp4` وملف `.txt` (العنوان/الوصف/الوسوم للنسخ واللصق)،
وملف `upload_sheet.csv` يجمعها كلها. كل فيديو يستغرق 1–2 دقيقة للإنتاج.

## كيف يمنع النظام التكرار؟
كل فيديو يُخطَّط قبل تسجيله، وكل عنصر يُختار بقاعدة «الأقدم استخدامًا» مقابل سجل `data/history.json`:
- **9 أفكار (concepts)**: لاعب محترف، فشل بسبب نحلة، لاعب مبتدئ، صيد الصاعقة، إنقاذ في آخر الثواني، بلا نحل، سرعة جنونية، خمّن النتيجة، صيد النملة الذهبية. لا تتكرر الفكرة مرتين متتاليتين، ولا تطغى فكرة على غيرها.
- **6 ثيمات بصرية** (حديقة، ليل، حلوى، صحراء، حمم، ثلج): لا يتكرر الثيم في فيديوين متتاليين.
- **نص الافتتاح (hook)** و**نص النهاية (CTA)** بأربعة أشكال بصرية مختلفة، تدور بالتناوب.
- **موسيقى مولّدة** بخمسة أساليب، بمقام وإيقاع ومقطوعة مختلفة لكل فيديو (لا يتكرر المقام ولا الإيقاع القريب).
- **مصدر عشوائية (seed)** لا يتكرر أبدًا، فتختلف مواضع النمل وتوقيتاتها في كل جولة، ويختلف أسلوب البوت قليلًا.
- **العنوان** يُفحص بالتشابه مع آخر 40 عنوانًا ولا يُقبل المشابه. الوصف والوسوم والهاشتاقات تدور كذلك.
- **فحص الجودة**: إذا لم تتحقق الفكرة (مثلًا «فشل بسبب نحلة» ولم تُضرب نحلة) يعيد المصنع التسجيل بسيد جديد.
- يحذّرك `report` إذا طغت فكرة واحدة أو تشابهت العناوين أو أنتجت الكثير في يوم واحد.

لإضافة تنوع أكثر: عدّل `src/data.js` (جمل افتتاح، عناوين، أفكار جديدة…) والمصنع سيستخدمها تلقائيًا.

## نصائح مهمة للنشر
- لا تنشر أكثر من 1–3 فيديوهات يوميًا، ووزّعها على اليوم. يوتيوب قد يقيّد القنوات التي تنشر كمية كبيرة من فيديوهات متشابهة (المحتوى المتكرر).
- شاهد كل فيديو قبل رفعه. إن لم يعجبك أنتج غيره.
- اللعبة تُشغَّل تلقائيًا بوضع `?shorts` (بلا إعلانات ولا أزرار تثبيت/مشاركة). الفيديو يعرض شارة ثابتة «Play FREE — link in bio» (نصها في `config.json` عند `bioText`) والوصف يحتوي سطرًا يوجّه إلى الرابط في البايو. ضع رابط اللعبة في بايو القناة.

## ملفات
- `game/` نسخة اللعبة (فيها الثيمات وخيارات `time=` و`theme=` ووضع `shorts`). ارفعها لموقعك كما هي.
- `src/` الكود: `planner.js` (منع التكرار)، `bot.js` (اللاعب الآلي)، `record.js` (التسجيل)، `audio.js` (الصوت)، `meta.js` (العناوين).

## التشغيل التلقائي على GitHub (فيديو كل يومين → تيليجرام)
1. أنشئ مستودعًا جديدًا على GitHub وارفع **محتويات هذا المجلد** إلى جذر المستودع (يجب أن يكون المجلد `.github` في الجذر).
2. أنشئ بوتًا من @BotFather وخذ التوكن، واحصل على معرّف الدردشة (Chat ID) من @userinfobot (وأرسل للبوت رسالة `/start` أولًا).
3. من المستودع: **Settings → Secrets and variables → Actions → New repository secret**، وأضف:
   - `TELEGRAM_BOT_TOKEN`
   - `TELEGRAM_CHAT_ID`
4. **Settings → Actions → General → Workflow permissions** اختر **Read and write permissions**.
5. للتجربة الآن: تبويب **Actions → Make Short and send to Telegram → Run workflow**.

- التشغيل التلقائي يوميًا الساعة 12:00 UTC لكنه ينفّذ فعليًا **كل يومين** (غيّر الساعة من `cron` في `.github/workflows/make-short.yml`).
- يُحفظ `data/history.json` تلقائيًا في المستودع حتى لا تتكرر الأفكار.
- يصلك على تيليجرام الفيديو، ثم رسالة فيها العنوان والوصف والوسوم للنسخ إلى يوتيوب.
- مدة الفيديو 20 ثانية: عدّاد 3 ثوانٍ + لعب 14 ثانية + ختام. (`config.json`: `gameSeconds`, `videoSeconds`)
